# ARC Updated Workflow Map

1. Case Intake
2. Evidence Collection
3. Preliminary Investigation Analysis
   - Lead Development Workspace
   - Intelligence Board
   - OUI and Drug Defense Analyzer
4. Field Investigation
5. Supplemental Records
6. Forensic Video Audit
7. Legal Research
8. Final Case Synthesis
9. Findings Approval
10. Report Builder and Finalization
   - Build and lock one master report
   - Generate formal PDF
   - Generate interactive attorney HTML
   - Generate offline client dashboard ZIP

## Controlling Report Flow

Approved case materials -> Master report -> Draft review -> Content lock -> PDF + attorney HTML + offline ZIP.

All outputs must use the same master report content. They must not be independently regenerated by AI.
