    Deployment and evidence-security findings

    • Browser-local API keys are readable by JavaScript running under the same origin. This is functional, not a hardened secret-management design.
    • Vercel storage is durable only when KV/Upstash variables are configured. Otherwise hosted data can fall back to temporary storage.
    • The optional ARC_ACCESS_TOKEN is a shared gate, not full user authentication or case-level authorization.
    • Hosted uploads are limited by Vercel request-body limits; the local server remains the path for large evidence.
    • The Intelligence Board Gemini endpoint is presented as future secure-server functionality and is not a complete default API route in this ZIP.
    • Final reports require investigator/attorney review because prompt rules preserve uncertainty but cannot verify facts outside supplied records.
