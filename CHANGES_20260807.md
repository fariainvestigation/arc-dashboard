Everything below was verified in a sandbox against emulated D1/R2, stubbed
providers, and a simulated browser. Nothing here has run against live
Cloudflare Access, D1, R2, or a real provider. See `docs/DEPLOYMENT.md`.

Syntax sweep clean across all JS, MJS, and inline HTML. No em dashes. No live
provider keys anywhere in the package.

## Defects found and fixed

1. `stripTags()` deleted `[AUTH:id]` tags instead of resolving them, so filed
   motions read "See , at 476." Every case citation was being dropped from the
   document going to the judge. Now resolves to case name and reporter cite.
2. `stripTags()` used `\s*` after each tag, which consumed the newlines between
   paragraphs and collapsed multi-paragraph arguments into one block.
3. The AI gateway wrote `provider_log` using column names that do not exist in
   `schema.sql` (`in_chars`, `out_chars`, `note`). Logging is inside a
   try/catch, so every AI call would have silently recorded nothing.
4. Filing review built its consistency-check text from section `body` only, so
   structured caption data in `meta` was invisible to the docket and client
   checks.
5. Two OUI components gated AI availability on `VITE_GEMINI_API_KEY` existing.
   Removing the bundled key would have silently disabled AI rather than failing.
6. 47 em dashes across 13 files. An earlier scan missed them because `grep -P`
   was not matching multibyte characters without a UTF-8 locale.

## New

- `shared/arc_case_link.js` - progressive enrichment. Fills missing case fields
  from any module, records conflicts instead of overwriting, and installs the
  `window.ARCBridge` shim that Motion & Legal needs.
- `cloudflare-worker/ai/arc_ai_gateway.mjs` - one AI entry point. Claude writes
  motions and the final report; Gemini does everything else. Enforced
  server-side from the task name.
- `shared/arc_ai_client.js` - browser client. No module holds a key.
- `shared/arc_final_report_writer.js` - Claude drafts the final report from
  approved, source-tagged material only. Discards any draft citing material
  outside the approved set.
- `cloudflare-worker/legal/arc_motion_render.mjs` - court-formatted motion
  rendering. Two-column Massachusetts caption with the docket on the right,
  split signature block, footer page numbers, no letterhead.
- `modules/current-arc-pages/arc_preflight.html` - browser preflight for the
  failures that are otherwise silent.
- `docs/DEPLOYMENT.md` - nine ordered steps, each with a check.

## Changed

- `01_Case_Dashboard.html` now publishes attorney, charges, county, and
  attorneyFirm, plus alias names. County added to the case record and form.
- OUI app routes all Gemini traffic through the gateway. No key in the bundle.
- Report Package Builder has a "Draft from approved record" button.
- Gemini model ladder normalized to 3.6-flash, 2.5-flash, flash-latest, with
  automatic walk-down on a retired model ID.
- Access JWT verification now checks the `iss` claim.

## Not done

- Nine shared root files are still absent from this package, including
  `arc_unified_bridge.js`. The `ARCBridge` shim assumes method names in that
  file that have never been verified. Preflight reports this in seconds.
- Four modules still call `ARCGemini` with the browser key: Chain of Custody
  Review, Chain of Custody Analyzer, Forensic Video Audit, Intelligence Board.
  They work; they are not yet on the gateway.
- Field conflicts accumulate with no resolver UI. The API is tested; preflight
  reports the count.
- Both `wrangler.toml` files still hold placeholders, by design.
