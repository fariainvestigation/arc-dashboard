ARC Provider Setup

ARC never accepts provider keys in a webpage. Enter each secret only through Wrangler on a trusted administrator machine.

AI Worker

Gemini analysis + Claude final reports.

cd cloudflare-worker/ai
wrangler secret put GOOGLE_API_KEY
wrangler secret put ANTHROPIC_API_KEY
wrangler deploy

Route: /ai/*

Legal Worker

CourtListener + Claude motion drafting.

cd cloudflare-worker/legal
wrangler secret put COURTLISTENER_API_KEY
wrangler secret put ANTHROPIC_API_KEY
wrangler deploy

Route: /legal-api/*

Research Worker

Firecrawl public-web research.

cd cloudflare-worker/research
wrangler secret put FIRECRAWL_API_KEY
wrangler deploy

Route: /research-api/*

Security rule

Never paste Gemini, Claude, CourtListener, or Firecrawl credentials into ARC HTML, localStorage, case files, prompts, exports, GitHub, or ZIP packages. Wrangler secrets are entered interactively and are not printed back.
